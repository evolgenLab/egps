Raw Data Upload
The first file we expected is the sequence file(*.csfasta), the second file we excepted is the quality file(*.qual). All the files should be compressed (*.zip or *.tar.gz) before upload. The size of each file must be less than 1GB,the total size of the files must be less than 2GB.
