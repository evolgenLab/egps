# eGPS 软件下载安装

欢迎访问 eGPS 软件官方下载站。

eGPS 是一套用于基因组学和进化数据分析的工具。本网站提供已发布的 eGPS 桌面软件、用户手册、测试数据及相关软件资源。

## 可下载内容

网站提供以下资源：

- Windows 和 macOS 版 eGPS 桌面软件
- eGPS v1.x 和 v2.x 版本
- 中文和英文用户手册
- R4eGPS R 软件包
- 测试数据
- Coronavirus GenBrowser 下载文件

具体下载链接请见网站页面。较大的安装包和配套文件通过 GitHub Releases 提供下载。
